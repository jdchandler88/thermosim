# WP11: GUI integration and Windows launch

**Wave:** 3 · **Size:** M · **Depends on:** WP08 and WP09 merged (WP10 Part A
for the quick estimate).

## Goal

Connect the GUI to the real simulator, polish the real-time experience, and
make it easy to install and launch on Windows.

## Owns

- `src/thermosim/gui/integration.py`
- `src/thermosim/gui/runner_factory.py` (taken over from WP08)
- `packaging/**`
- `docs/user-guide.md`
- `tests/gui_integration/**`
- **Small fixes elsewhere in `gui/`:** allowed, but list each in the PR
  description, since WP08 is finished by then.

## Requirements

1. **Runner:** `make_runner` returns `SimulationRunner`. `--fake` still
   selects `FakeRunner`, which stays useful for UI development.
2. **Before a run**, in a background thread with a modal progress dialog that
   can be cancelled:
   - build the domain, to show geometry errors (for example "element above
     liquid") inline in the editor next to the offending field;
   - show the cell count and estimated run time. Warn if the estimate exceeds
     10 minutes, and offer the preview cell size.
3. **First-run Numba compile:** show "Preparing solver (first run only)…"
   while the JIT warm-up runs. It's cached afterwards.
4. **Quick estimate:** a button and panel showing the lumped model's (WP10)
   time-to-target in under 1 s, before running the full simulation.
5. **Real-time mode polish:**
   - The power slider's changes appear on the chart's power trace within one
     poll tick.
   - Keyboard shortcuts: Space toggles pause, ↑/↓ change power by ±5%, and
     +/− change speed.
6. **Saving runs:**
   - "Save run…" stores a `save_run` directory; "Open run…" loads one into
     playback mode (no live runner).
   - A run that finishes unsaved prompts before it's discarded.
7. **Windows launch:**
   - `packaging/windows/README.md` gives step-by-step install instructions:
     install `uv`, `uv tool install` from the git URL or run `uv run thermosim
     gui` in a clone.
   - `packaging/windows/thermosim.bat` is a double-click launcher.
   - **Optional stretch** (ask the coordinator first): a PyInstaller spec
     producing a one-folder `.exe`, plus a CI job that builds it on
     `windows-latest` and uploads it as an artifact.
8. **`docs/user-guide.md`:** with screenshots (generated by the offscreen
   screenshot test). Covers creating a setup, running in fast mode, real-time
   mode, reading the outputs, importing measured data and comparing, and what
   each setting means physically.

## Acceptance criteria

- pytest-qt: load an example, run it for real at dx = 0.02 in fast mode to
  completion, and check that the summary panel shows the time-to-target
  matching `run_headless` on the same scenario within 1e-9.
- A real-time run at 10× responds to the power slider: delivered power in the
  samples changes within 1 s of sim time.
- A geometry error is shown on the right field.
- Save run → Open run → scrubbing works.
- A manual Windows checklist in the PR (by the user or a Windows CI artifact
  screenshot): installs per the README, launches, completes a run.
